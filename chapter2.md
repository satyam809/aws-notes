# ☁️ Cloud Computing — Short Notes

### 🌐 Cloud Computing

> **Using IT resources like servers, storage & databases over the Internet.**

💰 **Pay only for what you use** → Pay-as-you-go

---

### 🤔 Why Cloud?

* 💰 No need to buy expensive hardware
* 📈 Easily **scale** resources up/down
* ⚡ Quick deployment
* 🔧 Less hardware management
* 🌍 Access resources over the Internet

---

### ⚙️ Service Models

**1️⃣ IaaS — Infrastructure as a Service**

> Gives you **basic infrastructure**.

```text
You manage → OS + Apps
Cloud → Server + Storage + Network
```

**Example:** AWS EC2

---

**2️⃣ PaaS — Platform as a Service**

> Gives you a **ready platform to build & deploy apps**.

```text
You manage → Your Application
Cloud → OS + Runtime + Infrastructure
```

**Example:** AWS Elastic Beanstalk

---

**3️⃣ SaaS — Software as a Service**

> Ready-to-use **software over the Internet**.

```text
You → Use the Software
Cloud → Manages Everything
```

**Example:** Gmail, Google Docs

---

### 🏢 Deployment Models

**🌍 Public Cloud**

> Shared cloud infrastructure.

Example: **AWS, Azure**

**🔒 Private Cloud**

> Cloud dedicated to **one organization**.

**🔄 Hybrid Cloud**

> **Public + Private Cloud** together.

---

### 🧠 Easy Memory Trick

**Service Models:**

> **IaaS → Infrastructure**
> **PaaS → Platform**
> **SaaS → Software**

**Deployment:**

> 🌍 **Public** → Shared
> 🔒 **Private** → One organization
> 🔄 **Hybrid** → Both
