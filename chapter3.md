# ☁️ AWS — Short Notes

### 🚀 What is AWS?

> **AWS (Amazon Web Services)** is a cloud platform that provides **IT resources over the Internet**.

Examples:

* 🖥️ Computing
* 💾 Storage
* 🗄️ Databases
* 🌐 Networking
* 🤖 Machine Learning

---

### ⭐ Why AWS?

* 📈 **Scalable** → Increase/decrease resources easily
* 🌍 **Global** → Available around the world
* 🔒 **Secure**
* 🛡️ **Reliable**
* 💰 **Pay-as-you-go**

---

### 🌎 AWS Infrastructure

```text
AWS
 ↓
🌍 Regions
 ↓
🏢 Availability Zones (AZs)
 ↓
🖥️ Data Centers
```

**Region** → A geographical location where AWS has infrastructure.

**Availability Zone (AZ)** → One or more isolated data centers inside a Region.

👉 Multiple AZs help keep applications **available even if one AZ has problems**.

---

### 💰 AWS Free Tier

> AWS provides **free usage limits** on selected services for learning and experimentation.

⚠️ Always check the current pricing/free-tier limits before using resources.
